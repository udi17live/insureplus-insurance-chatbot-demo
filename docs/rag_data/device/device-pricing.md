# Device Insurance Pricing

> Insure Plus device insurance uses fixed annual premiums based on the declared device value band and device type.

## Annual Premiums by Declared Value Band

The following rates apply to all device types (smartphone, tablet, laptop).

Declared value up to £200: £40 per year.
Declared value £201–£400: £65 per year.
Declared value £401–£600: £90 per year.
Declared value £601–£800: £115 per year.
Declared value £801–£1,000: £140 per year.
Declared value above £1,000: £170 per year.

## Device Type Adjustment

Smartphones pay the base rate for their value band. Tablets have £10 added to the base rate. Laptops have £20 added to the base rate, reflecting higher repair costs.

## No Age or Mileage Factors

Device insurance premiums do not vary by policyholder age, location, or usage. Only declared value and device type affect the premium.

## Example Quotes

A smartphone declared at £550: base rate for £401–£600 band = £90 per year (£7.50 per month). A laptop declared at £750: base rate for £601–£800 band = £115 + £20 laptop addition = £135 per year (£11.25 per month). A tablet declared at £350: base rate for £201–£400 band = £65 + £10 tablet addition = £75 per year (£6.25 per month).

## Excess Reminder

All device claims are subject to a £50 excess regardless of the premium tier.
